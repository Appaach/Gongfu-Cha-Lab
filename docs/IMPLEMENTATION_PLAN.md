# Gongfu Cha Lab — Поэтапный план реализации (Implementation Plan)

**Версия документа:** 0.1.0-alpha  
**Горизонт планирования:** Этапы 1–5  

---

## Этап 1: Архитектурный фундамент и рабочий каркас интерфейса (ТЕКУЩИЙ ЭТАП)
**Цель:** Создать надёжную типобезопасную основу, предметную модель, интерфейсную лабораторию и проектную документацию без преждевременного внедрения сырых формул.

- [x] Определение архитектурных принципов (неизвестное не равно 0, типизация источников данных, изоляция ядра).
- [x] Проектирование предметной модели: `TeaSample`, `BrewingMethod`, `BrewingVessel`, `ValueWithOrigin`.
- [x] Подготовка исчерпывающей проектной документации (`PRODUCT_SPEC.md`, `DOMAIN_MODEL.md`, `MODEL_DESIGN.md`, `IMPLEMENTATION_PLAN.md`).
- [x] Реализация структуры директорий (`src/domain/`, `src/engine/`, `src/features/`, `src/data/`, `src/components/`, `src/tests/`).
- [x] Создание интерфейса чайной лаборатории:
  - Единая навигация (Симулятор, Каталог чаёв, Мои чаи, Научная модель, Настройки);
  - Экран симулятора с настройкой 3 методов (Гунфу Ча, Лю Гэнь Пао, Открытое настаивание) и явным указанием единиц измерения;
  - Каталог эталонных чаёв с отображением статусов происхождения данных (`measured`, `estimated`, `unknown`);
  - Форма добавления пользовательского чая с указанием источника каждого поля;
  - Экран результатов с честным информированием о готовности физико-химического ядра;
  - Справочник научной модели с описанием уравнений и физических эффектов.
- [x] Настройка тестов предметной модели и проверка сборки.

## Этап 2: Гидродинамика и тепловой баланс посуды
**Цель:** Математическое моделирование температуры жидкости и удержания влаги листом.

- [ ] Моделирование охлаждения посуды:
  - Уравнение теплоотдачи Ньютона–Рихмана с учётом теплоёмкости материала (фарфор, исинская глина, боросиликатное стекло);
  - Температурное падение при вливании кипятка в ненагретую/прогретую посуду.
- [ ] Физика гидратации и удержания раствора:
  - Расчёт объёма удерживаемой влаги в листе ($2.0 - 3.2$ г/г) в зависимости от морфологии;
  - Расчёт эффективного остаточного объёма жидкости между проливами для методов Гунфу Ча и Лю Гэнь Пао;
  - Ступенчатое разбавление для метода Лю Гэнь Пао ($V_{\text{retained}} / V_{\text{total}}$).
- [ ] Модульные тесты теплового баланса и материального баланса массы воды.

## Этап 3: Физико-химическое ядро экстракции (TDS и выход сухих веществ)
**Цель:** Реализация нестационарной диффузионной модели выхода общего сухого остатка.

- [ ] Моделирование раскрытия листа (кинетика гидратации скрученных сферических и прессованных форм).
- [ ] Реализация диффузионного уравнения первого порядка с температурным коэффициентом Аррениуса.
- [ ] Расчёт выхода общего экстракта:
  - TDS настоя (мг/л, % растворимости);
  - Коэффициент истощения листа от пролива к проливу (Exhaustion Curve).
- [ ] Валидация модели на экспериментальных рядах измерений оптическим рефрактометром.

---

## Этап 4: Разделение химических фракций (Кофеин, Катехины, Теанин)
**Цель:** Дифференцированный расчёт выхода биологически активных соединений с разной молекулярной массой.

- [ ] Введение индивидуальных эффективных коэффициентов диффузии ($D_{\text{theanine}} > D_{\text{caffeine}} > D_{\text{EGCG}} > D_{\text{thearubigins}}$).
- [ ] Оценка сенсорных предикторов:
  - Соотношение сладость/горечь (индекс аминокислоты к полифенолам);
  - Плотность тела настоя (водорастворимые пектины и полисахариды).
- [ ] Интервальные графики концентрации с отображением доверительных интервалов погрешности.

---

## Этап 5: Оптимизатор рецепта под вкусовую цель (Inverse Recipe Fitting)
**Цель:** Алгоритмический подбор оптимального протокола заваривания под желаемый баланс.

- [ ] Интерфейс постановки задачи (целевой уровень экстракции, желаемая доминанта: мягкость, терпкость, бодрящий эффект).
- [ ] Итерационный алгоритмический поиск (градиентный спуск или симплекс-метод Нелдера–Мида) по варьируемым параметрам (навеска, температура, экспозиция).
- [ ] Экспорт протокола заваривания в формате лабораторного отчёта.
