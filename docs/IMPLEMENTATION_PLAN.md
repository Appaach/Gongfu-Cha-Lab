  - Сворачивание лабораторных химических полей (по умолчанию статус `unknown`, `value: null`).
- [x] **Разделение физических и химических понятий в `TeaSample`**:

- [x] **Верификация и тесты**:

## Этап 2A: Тепловой баланс сосуда и жидкости (ЗАВЕРШЕНО)
**Цель:** Математическое моделирование температуры жидкости во времени по двухузловой схеме сосредоточенных теплоёмкостей.

- [x] **Независимый модуль `src/engine/thermal/`**:
  - Строгие физические размерности: температура (°C), время (с), объём (мл), массы (г/кг), $c_p$ (Дж/(кг·К)), $C$ (Дж/К), проводимость $G$ (Вт/К);
  - Исключение безразмерного `thermalInertiaFactor` из физических уравнений теплообмена;
  - Справочная удельная теплоёмкость воды $c_p = 4184\text{ Дж/(кг}\cdot\text{К)}$ и плотность $\rho = 1.0\text{ г/мл}$.
- [x] **Профили стандартных сосудов (`VesselThermalProfile`)**:
  - Фарфоровая гайвань 110 мл ($m_v = 120\text{ г}$, $c_p = 880\text{ Дж/(кг}\cdot\text{К)}$, $G_{lv} = 4.2$, $G_{va} = 0.75$, $G_{la} = 0.35\text{ Вт/К}$);
  - Исинский глиняный чайник 130 мл ($m_v = 140\text{ г}$, $c_p = 920\text{ Дж/(кг}\cdot\text{К)}$, $G_{lv} = 3.6$, $G_{va} = 0.60$, $G_{la} = 0.12\text{ Вт/К}$);
  - Боросиликатная кружка 350 мл ($m_v = 160\text{ г}$, $c_p = 830\text{ Дж/(кг}\cdot\text{К)}$, $G_{lv} = 3.2$, $G_{va} = 0.95$, $G_{la} = 0.85\text{ Вт/К}$);
  - Статус всех оценочных параметров строго зафиксирован как `model_profile`.
- [x] **Численный интегратор теплообмена**:
  - Решение связанных линейных ОДУ для узлов жидкости и стенок методом Рунге-Кутты 2-го порядка (метод Хойна) с шагом $\Delta t = 0.1\text{ с}$;
  - Точный расчёт температуры смеси по балансу тепловой энергии $T_{\text{mixed}} = (V_1 T_1 + V_2 T_2)/(V_1 + V_2)$;
  - Физический контроль границ: невозможность создания энергии или появления температур за пределами термодинамического диапазона.
- [x] **Поддержка трёх методов заваривания**:
  - Гунфу Ча: учёт динамики охлаждения и паузы между проливами (пустой сосуд на воздухе);
  - Лю Гэнь Пао: расчёт температуры смешения долива с сохранённым корнем;
  - Ленивое заваривание в кружке: непрерывный теплообмен по шкале событий (заливка, отпивание, долив).
- [x] **Интерфейс и визуализация**:
  - График температурной динамики во времени (SVG) с кривыми настоя и стенок;
  - Разъяснение понятий: температура заливки vs температура настоя vs температура стенок vs температура воздуха;
  - Настройка предварительного прогрева сосуда и комнатной температуры.
- [x] **Автоматизированное тестирование**:
  - 12 физических инвариантных тестов теплового ядра.

## Этап 2A.1: Проверка корректности теплового ядра и аудит (ЗАВЕРШЕНО)
**Цель:** Устранение скрытых замен некорректных данных на нули, верификация численной сходимости интегратора, удаление ошибочных стандартов и строгая валидация методов заваривания.

- [x] **Искоренение ложных нулей и обработка ошибок (Unknown ≠ 0)**:
  - В `solveThermalMixing`: отрицательные или NaN объёмы вызывают `ThermalValidationError`;
  - Недопустимые температуры (< 0 °C или > 100 °C) вызывают явный `ThermalRangeError` (запрет скрытой замены на 0 °C);
  - Нулевой объём возвращает `temperatureC: null` (температура несуществующей жидкости не равна 0 °C);
  - В `integrateThermalStep`: для пустого сосуда ($V=0$) температура жидкости строго `null`, экстремумы `null`, узлы кривой содержат `liquidTemperatureC: null`.
- [x] **Анализ численной устойчивости и сходимости интегратора**:
  - Устранение необоснованных утверждений о «безусловной устойчивости» явного метода Хойна;
  - Анализ критерия устойчивости схемы: $\Delta t < 2 \tau_{\min}$; при рабочем $\Delta t = 0.1\text{ с}$ отношение $\Delta t / \tau_{\min} \le 0.007 \ll 2$;
  - Проведение численного теста сходимости при $\Delta t \in [0.2, 0.1, 0.05, 0.025]\text{ с}$: максимальное расхождение между $\Delta t = 0.1\text{ с}$ и детальным $\Delta t = 0.025\text{ с}$ составляет $< 0.005\text{ °C}$ ($\mathcal{O}(\Delta t^2)$);
  - Регистрация предупреждений численного интегратора при срабатывании стабилизации границ.
- [x] **Корректировка физических констант и литературных источников**:
  - Удаление ошибочной ссылки на ISO 5537 (стандарт влажности сухого молока); фиксация $22.0\text{ °C}$ как инженерного модельного приближения;
  - Уточнение рамок применения таблиц IAPWS для $c_p$ воды ($4184.0\text{ Дж/(кг}\cdot\text{К)}$, вариация $< 1\%$ в интервале 20–100 °C);
  - Явная фиксация проводимостей $G$ как интегральных (lumped) инженерных оценок.
- [x] **Строгая валидация методов заваривания**:
  - Превышение объёма посуды (в Гунфу, Лю Гэнь Пао или кружке) вызывает `BrewingCapacityOverflowError` и блокирует запуск расчёта в интерфейсе;
  - Пауза между проливами Лю Гэнь Пао по умолчанию задокументирована как $0.0\text{ с}$;
  - В методе Lazy Mug введена строгая валидация шкалы: запрет $t < 0$, строгая хронологическая монотонность $t_{i+1} > t_i$, запрет событий после `session_end`, запрет отпивания больше текущего объёма кружки.
- [x] **Расширенное тестирование**:
  - Расширение набора тестов до 16 тестовых блоков (всего 83 проверки), 100% прохождение без ошибок.

## Этап 2A.2: Строгая валидация теплового ядра и сценариев (ВЫПОЛНЕНО)
**Цель:** Полное устранение скрытой эвристической коррекции параметров, строгий контроль тепловых проводимостей, численного шага и структурной целостности шкалы событий.

- [x] **Строгая валидация тепловых проводимостей профиля**:
  - `conductanceLiquidVesselWPerK`, `conductanceVesselAmbientWPerK`, `conductanceLiquidAmbientWPerK` проверяются на конечность и неотрицательность ($\ge 0$);
  - Значение $0\text{ Вт/К}$ разрешено как физически обоснованное модельное приближение (адиабатическая теплоизоляция крышки или стенок);
  - Отрицательные значения, `NaN` и `Infinity` вызывают типизированный `ThermalValidationError` (`INVALID_CONDUCTANCE`);
  - Полностью удалены негласные фильтры `Math.max(0, ...)`.
- [x] **Валидация параметров численного интегрирования**:
  - Зафиксирован явный диапазон допустимого шага интегрирования в константах: $\Delta t \in [0.005, 0.5]\text{ с}$ (`MIN_INTEGRATOR_TIME_STEP_SECONDS`, `MAX_INTEGRATOR_TIME_STEP_SECONDS`);
  - Выход за диапазон, отрицательный или бесконечный шаг выбрасывает `ThermalValidationError` (`INVALID_TIME_STEP`);
  - Удалено негласное сужение шага через `Math.min(0.2, Math.max(0.005, dt))`;
  - Интервал дискретизации `samplingIntervalSeconds` проверяется на строгую положительность ($> 0\text{ с}$) без скрытого `Math.max(0.1, ...)`.
- [x] **Валидация параметров симуляции (ThermalSimulationOptions)**:
  - Пауза между проливами `interInfusionPauseSeconds` проверяется на $\ge 0$ и конечность (`INVALID_PAUSE_DURATION`);
  - `ambientTemperatureC` проверяется на физический диапазон помещения $[-50, 80]\text{ °C}$;
  - `preheatedVesselTemperatureC` проверяется на диапазон прогрева $[0, 150]\text{ °C}$;
  - `integratorTimeStepSeconds` проверяется на соответствие интервалу устойчивости $[0.005, 0.5]\text{ с}$.
- [x] **Структурная валидация сценариев (в частности simulateLazyMug)**:
  - Минимальная структура: не менее 2 событий (`initial_pour` и `session_end`);
  - Первое событие: строго `initial_pour` с меткой времени $t = 0\text{ с}$;
  - Завершающее событие: строго единственное `session_end`, обязательно на последней позиции;
  - Запрет повторного или второго `initial_pour`;
  - Запрет любых событий после `session_end`;
  - Строгая монотонность меток времени: $t_{i+1} > t_i$;
  - Объёмы долива и отпивания строго $> 0$, отпивание не может превышать текущий объём кружки (`SIP_EXCEEDS_VOLUME`);
  - Температуры заливаемой воды валидируются на фазовые границы жидкости $0\text{–}100\text{ °C}$ (`ThermalRangeError`).
- [x] **Валидация метода Лю Гэнь Пао**:
  - Удалено скрытое ограничение доли удержания `Math.min(0.9, Math.max(0.1, ...))`;
  - `retainedLiquorFractionOfTotal` строго проверяется на принадлежность диапазону $[0, 1.0)$ (`INVALID_RETAINED_FRACTION`);
  - Проверены объём долива (`INVALID_ADDED_VOLUME`) и температура долива (`ThermalRangeError`).
- [x] **Тестовое покрытие**:
  - Добавлены 5 новых блоков тестов (Сюиты 17–21);
  - Общий объём тестов вырос с 83 до 130 проверок, все 130 тестов проходят успешно (100%).
