# Спецификация водного баланса и гидратации чайного листа (Этап 2B)

## 1. Назначение документа

Настоящий документ определяет физическую модель водного баланса чайного листа, разграничение водных компартментов, уравнения сохранения массы и границы достоверности данных для этапа 2B симулятора **Gongfu Cha Lab**.

Документ служит нормативной основой для последующей реализации численных модулей гидратации (этапы 2B.1–2B.3) и исключает появление псевдонаучных формул, взаимной подмены неэквивалентных величин и скрытого искажения материального баланса.

## 2. Аудит текущей модели данных чая

В текущей кодовой базе (`src/domain/tea/types.ts` и `src/data/referenceTeas.ts`) зафиксированы три параметра, относящиеся к физике листа:

1. **`waterAbsorptionRatio`** (единица: `г/г`, статус: `literature` или `model_profile`):
   - **Физический смысл**: предельная (равновесная) гравиметрическая влагоёмкость растительной матрицы листа при длительном контакте с горячей водой:
     $$R_{\text{abs, max}} = \frac{m_{\text{water, absorbed, max}}}{m_{\text{dry}}}$$
   - **Типичные значения в каталоге**: $2.6\text{–}3.1\text{ г/г}$ ($2.6$ для Лунцзина, $2.9$ для Бай Хао Инь Чжэнь, $3.1$ для Те Гуаньинь, $2.7$ для Да Хун Пао и Дянь Хуна).
   - **Границы применимости**: этот параметр описывает **термодинамический предел емкости**, но **не содержит информации о времени** его достижения. Сам по себе он не определяет, сколько воды лист впитает за первые 10, 20 или 40 секунд заваривания.

2. **`leafBulkDensityGPerCm3`** (единица: `г/см³`, статус: `model_profile`):
   - **Физический смысл**: насыпная плотность сухой навески в воздухе до контакта с водой:
     $$\rho_{\text{bulk, dry}} = \frac{m_{\text{dry}}}{V_{\text{bulk, dry}}}$$
   - **Типичные значения в каталоге**: $0.24\text{ г/см³}$ (пушистый белый чай) $\dots$ $0.60\text{ г/см³}$ (тугие сферы улуна) $\dots$ $0.75\text{ г/см³}$ (прессованный пуэр).
   - **Границы применимости**: характеризует макрогеометрию сухих частиц и объём воздуха между ними. **Не является плотностью ткани листа**, не определяет плотность влажного листа и не позволяет рассчитать гидравлическое сопротивление слоя без знания гранулометрии и геометрии сосуда.

3. **`uncalibratedHydrationSpeed`** (единица: `ед.`, статус: `model_profile`):
   - **Физический смысл**: качественный эвристический индекс относительной скорости смачивания листа ($0.35\text{–}1.5\text{ ед.}$).
   - **Критическое метрологическое ограничение**: эта величина **безразмерна**. Её категорически **нельзя** приравнивать к константе скорости в $\text{с}^{-1}$, делить на неё секунды ($t / v$) или автоматически переводить в постоянную времени $\tau$ без эмпирической калибровочной кривой.

### Метрологический статус эталонного каталога (`referenceTeas.ts`)

- Значения со статусом `origin: 'literature'` в `referenceTeas.ts` в настоящее время имеют обобщённые примечания (`sourceNotes`), но **не содержат валидированных библиографических ссылок** с указанием авторов, года, DOI или страницы (`citation: undefined`).
- Ни одно значение в каталоге не является поверенным лабораторным измерением конкретной партии чая пользователя.
- **Принцип неэквивалентности**:
  $$R_{\text{abs, max}}\text{ (влагоёмкость, г/г)} \not\equiv k_{\text{hyd}}\text{ (кинетика, с}^{-1}\text{)} \not\equiv \rho_{\text{bulk}}\text{ (насыпная плотность, г/см}^3\text{)}$$
  Попытка выразить одну из этих величин через другую без дополнительных физических измерений недопустима.

## 3. Разделение водных компартментов

Для исключения ошибок материального баланса и двойного учёта вводится строгая система непересекающихся физических компартментов воды.

```
+-------------------------------------------------------------------------------+
|                       ПОЛНАЯ МАССА ВОДЫ В СИСТЕМЕ                             |
+---------------------------------------+---------------------------------------+
|  КОМПАРТМЕНТ А:                       |  СВОБОДНАЯ ЖИДКАЯ ФАЗА В СОСУДЕ       |
|  Вода, поглощённая матрицей листа     |  (Компартмент B)                      |
|  m_abs(t), [г]                        |  m_free(t), [г] / V_free(t), [мл]     |
|  - Внутриклеточная влага              |  - Растворитель экстракта             |
|  - Внутрипоровые капилляры ткани      |  - Свободно циркулирует               |
|  - Не сливается самотёком             |  - Участвует в теплообмене            |
|                                       +-------------------+-------------------+
|                                       | ПРИ СЛИВЕ НАСТОЯ: | ПРИ СЛИВЕ НАСТОЯ: |
|                                       | Сливаемая фракция | Удерживаемая      |
|                                       | m_drained, [г]    | фракция           |
|                                       | V_drained, [мл]   | m_retained, [г]   |
|                                       |                   | V_retained, [мл]  |
+---------------------------------------+-------------------+-------------------+
```

### Компартмент A: Вода, поглощённая матрицей листа ($m_{\text{abs}}$, г)
- Вода, проникшая внутрь клеточной структуры и микропор растительной ткани листа.
- Связанная и набухающая фаза.
- **Не является частью свободного настоя**: в ней не происходит свободной объемной конвекции, она не может быть слита из сосуда самотёком при переворачивании гайвани или чайника.
- Изменяется от $m_{\text{abs}}(0) = 0$ до теоретического предела $m_{\text{abs, max}} = m_{\text{dry}} \cdot R_{\text{abs, max}}$.

### Компартмент B: Свободный настой ($V_{\text{free}}$, мл / $m_{\text{free}}$, г)
- Жидкая фаза, находящаяся в полости заварочного сосуда за пределами внутренней матрицы листа.
- Служит средой растворения, конвективного переноса тепла и химической диффузии.
- В любой момент времени до начала слива:
  $$m_{\text{free}}(t) = m_{\text{water, total}}(t) - m_{\text{abs}}(t)$$
  $$V_{\text{free}}(t) = \frac{m_{\text{free}}(t)}{\rho_w}$$

### Компартмент C: Интерстициальная удержанная жидкость ($V_{\text{interstitial}}$, мл / $m_{\text{interstitial}}$, г)
- Часть свободного настоя, которая после завершения свободного гравитационного слива удерживается капиллярными силами (менисками) в межчастичных зазорах между влажными листьями и тонкой плёнкой на их поверхности.
- **Принципиальное отличие от компартмента A**: интерстициальная жидкость находится *снаружи* ткани листа; её химический состав и температура в момент слива идентичны слитому настою.
- Обозначается как капиллярное гидродинамическое удержание: $V_{\text{interstitial}} = V_{\text{capillary, hold-up}}$.

### Компартмент D: Намеренно сохранённый корень настоя в Лю Гэнь Пао ($V_{\text{root, target}}$, мл)
- Объём свободного настоя, который заваривающий намеренно оставляет в сосуде согласно рецептуре метода Лю Гэнь Пао.
- Это управляющий параметр протокола заваривания, а не физическое свойство листа.

## 4. Правило исключения двойного учёта (Соотношение B, C и D)

Одной из главных ошибок моделирования является механическое сложение интерстициального удержания $V_{\text{interstitial}}$ и сохранённого корня $V_{\text{root}}$.

### Физическая картина
Интерстициальное удержание представляет собой капиллярный предел: жидкость, которую гравитация **не способна удалить** через щель крышки при полном переворачивании сосуда.
Если пользователь оставляет в сосуде объём $V_{\text{root, target}}$, превышающий объём межчастичных капилляров, листья остаются погруженными в этот придонный слой жидкости. Жидкость в межчастичных зазорах является неотъемлемой частью этого же самого остаточного объёма!

### Терминология и математическое правило
- `freeWaterVolumeMl` / `freeWaterBeforeDrainMl` — весь свободный настой вне внутренней водной фазы листа, включая жидкость в межчастичных зазорах;
- `capillaryHoldUpCapacityMl` — оценочная максимальная ёмкость удержания свободной жидкости капиллярами после гравитационного слива;
- `targetRootVolumeMl` — объём свободного настоя, который предписывает оставить рецепт:
  $$V_{\text{root, target}} = r \cdot V_{\text{free, pre}}$$
- `actualRetainedFreeWaterMl` — реальный остаток свободного настоя после слива с учётом технологической цели, капиллярной ёмкости и доступного объёма:
  $$V_{\text{retained, actual}} = \min\left(V_{\text{free, pre}},\, \max(V_{\text{root, target}},\, V_{\text{interstitial}})\right)$$
- `drainedFreeWaterMl` — фактически сливаемый объём настоя:
  $$V_{\text{drained, actual}} = V_{\text{free, pre}} - V_{\text{retained, actual}}$$

### Следствия правила:
1. **Гунфу Ча (полный слив)**: $r = 0 \implies V_{\text{root, target}} = 0$.
   $$V_{\text{retained, actual}} = \min(V_{\text{free, pre}},\, \max(0,\, V_{\text{interstitial}})) = \min(V_{\text{free, pre}},\, V_{\text{interstitial}})$$
   $$V_{\text{drained, actual}} = V_{\text{free, pre}} - V_{\text{retained, actual}}$$
   Сливается вся свободная жидкость за вычетом капиллярно удерживаемой влаги. Если доступной воды меньше капиллярной ёмкости, слив равен 0, фиктивная вода не генерируется.
2. **Лю Гэнь Пао (сохранение корней)**:
   - Если $V_{\text{root, target}} \ge V_{\text{interstitial}}$, то $V_{\text{retained, actual}} = \min(V_{\text{free, pre}}, V_{\text{root, target}}) = V_{\text{root, target}}$. Никакого дополнительного сложения с $V_{\text{interstitial}}$ не происходит.
   - Если пользователь задал долю удержания ниже капиллярного порога ($V_{\text{root, target}} < V_{\text{interstitial}}$), физика капиллярного удерживания оставляет в сосуде не менее $V_{\text{interstitial}}$.
3. **Строгое сохранение массы**:
   $$V_{\text{drained, actual}} + V_{\text{retained, actual}} \equiv V_{\text{free, pre}}$$
   с абсолютной точностью машинного эпсилон ($< 10^{-12}\text{ мл}$).

## 5. Уравнения баланса массы воды

### Единицы измерения и термодинамические допущения
- Масса воды: граммы ($\text{г}$).
- Объём жидкости: миллилитры ($\text{мл}$).
- Температура: градусы Цельсия ($^\circ\text{C}$).
- Плотность чистой воды принимается равной:
  $$\rho_w = 1.000\text{ г/мл} = 0.001\text{ кг/мл}$$
  *Допущение*: температурное расширение воды ($\approx 4\%$ в интервале от 20 до 100 °C) на этапе 2B не учитывается для сохранения аналитической замкнутости материального баланса.
- *Испарение*: на этапе 2B потери на испарение в накрытом крышкой сосуде принимаются равными нулю ($m_{\text{evap}} = 0$). Это инженерное допущение для закрытых сосудов, а не утверждение об абсолютном отсутствии испарения в природе.

### 5.1. Начало заваривания (Шаг 1, $t = 0$)
- Сухая навеска листа: масса $m_{\text{dry}}$ ($\text{г}$).
- Начальная поглощённая вода: $m_{\text{abs}}(0) = 0\text{ г}$.
- Заливка первой порции воды: объём $V_{\text{added}, 1}$ ($\text{мл}$), масса $m_{\text{added}, 1} = V_{\text{added}, 1} \cdot \rho_w$ ($\text{г}$).
- Начальный свободный настой:
  $$m_{\text{free}}(0^+) = m_{\text{added}, 1}$$

### 5.2. Поглощение воды во время контакта ($t \in [0, t_{\text{infusion}}]$)
Скорость поглощения воды сухим/набухающим листом описывается кинетической функцией:
$$\frac{d m_{\text{abs}}}{dt} = \dot{m}_{\text{abs}}\left(t, T, m_{\text{dry}}, R_{\text{abs, max}}, \dots\right) \ge 0$$

Интегральное поглощение за время пролива $\Delta t_k$:
$$\Delta m_{\text{abs}, k} = \int_{0}^{\Delta t_k} \dot{m}_{\text{abs}} \, dt$$

Физические ограничения:
1. Лист не может поглотить больше своего термодинамического предела:
   $$m_{\text{abs}}(t) \le m_{\text{abs, max}} = m_{\text{dry}} \cdot R_{\text{abs, max}}$$
2. Поглощение не может превышать физически доступный объём свободного настоя в сосуде:
   $$\Delta m_{\text{abs}, k} \le m_{\text{free, start}, k}$$

К концу контакта перед сливом:
$$m_{\text{abs}, k}^{\text{end}} = m_{\text{abs}, k}^{\text{start}} + \Delta m_{\text{abs}, k}$$
$$m_{\text{free, pre-drain}, k} = m_{\text{free, start}, k} - \Delta m_{\text{abs}, k}$$

### 5.3. Слив после пролива
- Вычисляется капиллярное удержание $m_{\text{interstitial}, k} = V_{\text{interstitial}, k} \cdot \rho_w$.
- В Лю Гэнь Пао вычисляется целевой корень: $m_{\text{root, target}, k} = r_k \cdot m_{\text{free, pre-drain}, k}$.
- Фактический остаток в сосуде:
  $$m_{\text{retained}, k} = \max\left(m_{\text{root, target}, k},\, m_{\text{interstitial}, k}\right)$$
- Сливаемый настой в чахай / пиалу:
  $$m_{\text{drained}, k} = m_{\text{free, pre-drain}, k} - m_{\text{retained}, k} \ge 0$$

### 5.4. Пауза между проливами и долив свежей воды (Шаг $k + 1$)
Во время паузы:
- Поглощённая вода $m_{\text{abs}}$ остаётся внутри листа (не испаряется и не вытекает).
- Свободный остаток $m_{\text{retained}, k}$ остаётся в сосуде и остывает вместе со стенками.

При доливе свежей порции воды $V_{\text{added}, k+1}$ при температуре $T_{\text{added}, k+1}$:
$$m_{\text{free, start}, k+1} = m_{\text{retained}, k} + V_{\text{added}, k+1} \cdot \rho_w$$
$$V_{\text{free, start}, k+1} = \frac{m_{\text{free, start}, k+1}}{\rho_w}$$

Смешение свободного настоя и свежей воды происходит по фундаментальному энергетическому балансу:
$$T_{\text{free, start}, k+1} = \frac{m_{\text{retained}, k} \cdot T_{\text{retained, end\_pause}} + m_{\text{added}, k+1} \cdot T_{\text{added}, k+1}}{m_{\text{free, start}, k+1}}$$

### 5.5. Глобальный закон сохранения массы сессии
Для любого шага $N$ сумма всех налитых объёмов воды строго равна сумме поглощённой, слитой и остаточной воды:
$$\sum_{k=1}^N m_{\text{added}, k} \equiv m_{\text{abs}}(t_N) + m_{\text{retained}, N} + \sum_{k=1}^N m_{\text{drained}, k}$$

- В таком случае расчёт поглощения переводится в режим `unknown_hydration_profile` с возвратом статуса неопределённости.

## 7. Разделение поведения трёх методов заваривания

### 7.1. Гунфу Ча (工夫茶)
- **Характер процесса**: импульсная экстракция с максимально полным сливом.
- **Водный баланс**:
  - На каждом шаге $k$ слив производится полностью ($r = 0$).
  - После слива в сосуде остаётся влажный лист с поглощённой водой $m_{\text{abs}, k}$ и интерстициальным удержанием $m_{\text{interstitial}, k}$.
  - Между проливами пустой сосуд остывает на воздухе; остаточная влага на листьях испаряется слабо в закрытом сосуде.
  - На шаге $k+1$ свежая вода смешивается с микрообъёмом $V_{\text{interstitial}}$, температура смеси практически равна температуре свежего кипятка (из-за малого объёма удержания).

### 7.2. Лю Гэнь Пао (留根泡)
- **Характер процесса**: ступенчатое разбавление с непрерывным буферным раствором («корнем»).
- **Водный баланс**:
  - Доля $r$ (`retainedLiquorFractionOfTotal`) применяется **строго к свободному настою** $V_{\text{free, pre}}$, а не к объёму залитой воды и не к поглощённой листом влаге.
  - Условие $V_{\text{retained}} = \max(r \cdot V_{\text{free, pre}}, V_{\text{interstitial}})$ гарантирует физическую реализуемость слива.
  - На следующем шаге свежая вода смешивается с остывшим за время паузы корнем.

### 7.3. Lazy Mug (Заваривание в кружке / 杯泡法)
- **Характер процесса**: квазинепрерывный контакт при высоком разбавлении.
- **Водный баланс**:
  - Слива настоя через сито нет: листья остаются на дне кружки на протяжении всей сессии.
  - Событие «отпивание» (`sip_consumption`) удаляет жидкость **исключительно из свободного настоя** $V_{\text{free}}$.
  - Вода $m_{\text{abs}}$, поглощённая листом, не уменьшается при отпивании!
  - Событие «долив» (`water_refill`) увеличивает $V_{\text{free}}$ и смешивает температуры свободной фазы.

## 8. Набухание и гидравлическое сопротивление слоя листьев

### Почему насыпной плотности сухого листа ($\rho_{\text{bulk, dry}}$) недостаточно?
Сухая насыпная плотность описывает геометрическую упаковку хрупких, скрученных или спрессованных частиц в воздухе. После смачивания горячей водой происходят сложные физико-механические процессы:
1. **Релаксация механических напряжений**: скрученные листья раскручиваются, распрямляя пластинку листа.
2. **Осмотическое и капиллярное набухание**: объём клеточных стенок увеличивается в $1.5\text{–}3.0$ раза.
3. **Формирование пористой среды**: в объёме сосуда формируется волокнистый сжимаемый слой с переменной пористостью $\varepsilon(t)$.
4. **Гидравлическое сопротивление** фильтрации описывается законом Дарси–Кармана:
   $$-\frac{dP}{dz} = \frac{\mu}{K} v = \frac{\mu \, c \, S_v^2 (1 - \varepsilon)^2}{\varepsilon^3} v$$
   где $S_v$ — удельная смоченная поверхность частиц ($\text{м}^2/\text{м}^3$), $\varepsilon$ — пористость слоя, $\mu$ — динамическая вязкость воды, $c$ — константа Козени.

Ни одна из величин ($S_v, \varepsilon, K$) не может быть выведена из одной лишь насыпной плотности $\rho_{\text{bulk, dry}}$ без знания:
- формы скрутки (сферическая, продольная, почка);
- распределения частиц по размерам (гранулометрии);
- площади поперечного сечения и геометрии сита/щели сосуда;
- степени механической деформации слоя под действием перепада давления при сливе.

### Вывод и фиксация статуса
Моделирование гидравлического сопротивления и гидродинамики скорости слива требует специализированного измерительного стенда (определение проницаемости слоя $K$ при фильтрации).
В текущей версии модели гидравлическое сопротивление и динамика струи слива фиксируются как **отложенные компоненты со статусом `unknown`**. Скорость слива принимается квазистационарной инженерной оценкой.

## 10. Реализованный API водного баланса (`src/engine/water-balance/`)

Модуль спроектирован в виде детерминированных чистых функций, полностью изолированных от теплового ядра, React, DOM и состояния сессии:

1. `calculateMaxAbsorbedWater(dryLeafMassGrams: number, maxAbsorptionRatioGramsPerGram: number): number`
   - Рассчитывает предельную влагоёмкость $m_{\text{abs, max}} = m_{\text{dry}} \cdot R_{\text{abs, max}}$ (г).
   - Строгая валидация: $m_{\text{dry}} > 0$, $R_{\text{abs, max}} \ge 0$. Не рассчитывает скорость.

2. `calculateSaturationHydrationRequested(dryLeafMassGrams, currentAbsorbedWaterGrams, maxAbsorptionRatioGramsPerGram, hydrationRateConstantPerSecond, durationSeconds): number`
   - Аналитически вычисляет запрашиваемое кинетикой насыщения поглощение влаги:
     $\Delta m_{\text{req}} = (m_{\text{dry}} \cdot R_{\text{abs, max}} - m_{\text{abs}}) \cdot (-Math.expm1(-k_{\text{hyd}} \cdot \Delta t))$.
   - Строгая валидация: $m_{\text{dry}} > 0$, $m_{\text{abs}} \ge 0$, $R_{\text{abs, max}} \ge 0$, $k_{\text{hyd}} \ge 0$, $\Delta t \ge 0$.
   - Численно устойчиво для малых $k \Delta t$.

3. `stepHydrationKinetics(params: HydrationKineticsStepParams): HydrationKineticsStepResult`
   - Выполняет полный шаг кинетики гидратации:
     - Аудирует полноту метаданных всех переданных параметров до проверки их достаточности.
     - При отсутствии данных возвращает `status: 'unknown_hydration_profile'` с информативным объяснением на русском языке (Unknown ≠ 0), возвращая `null` для запрошенных и фактических масс.
     - Проверяет единицы измерения (`s^-1`, `с^-1`, `г/г`, `g/g`).
     - Вычисляет запрашиваемое поглощение и вызывает `applyWaterAbsorption` для проверки ограничений и соблюдения закона сохранения массы.
     - Возвращает `status: 'calculated'`, фактически поглощённую массу, новые массы фаз, `limitingFactor`, невязку баланса и диагностические замечания.

4. `applyWaterAbsorption(params: WaterAbsorptionParams): ApplyAbsorptionResult`
   - Переносит воду из свободного компартмента $V_{\text{free}}$ в связанную матрицу листа $m_{\text{abs}}$.
   - Ограничивает поглощение остаточной влагоёмкостью листа и доступной свободной водой в сосуде.
   - Возвращает `limitingFactor` (`unconstrained`, `limited_by_leaf_capacity`, `limited_by_available_free_water`, `limited_by_both`, `zero_requested`).
   - Гарантирует сохранение массы: $\Delta m = 0$ с машинной точностью.

5. `solveLiquorDrain(params: DrainParams): DrainResult`
   - Рассчитывает слив свободного настоя с учётом цели рецепта ($r$) и капиллярного порога ($V_{\text{interstitial}}$).
   - Вычисляет: $V_{\text{retained, actual}} = \min(V_{\text{free, pre}}, \max(r \cdot V_{\text{free, pre}}, V_{\text{interstitial}}))$.
   - Возвращает слитый объём $V_{\text{drained}} = V_{\text{free, pre}} - V_{\text{retained, actual}}$ и лимитирующий фактор (`exact_target`, `governed_by_capillary_hold_up`, `insufficient_water_for_capillary_hold_up`, `zero_water`).
   - При `capillaryHoldUpCapacityMl === null` выбрасывает `UnknownCapillaryHoldUpError` (Unknown ≠ 0).

6. `simulateGongfuWaterBalance(session: GongfuSessionConfig, tea: TeaSample, options?: GongfuWaterBalanceOptions): GongfuWaterBalanceResult`
   - Выполняет пошаговый детерминированный расчёт водного баланса классической сессии Гунфу Ча:
     - Проверяет соответствие `session.teaId === tea.id` и допустимость параметров;
     - Накапливает поглощённую влагу $m_{\text{abs}}$ внутри листа;
     - Переносит остаточную капиллярную влагу между проливами;
     - При отсутствии $k_{\text{hyd}}$ возвращает `unknown_hydration_profile` и блокирует зависимые последующие шаги (`blocked_by_unknown_prior_state`);
     - При отсутствии капиллярной ёмкости фиксирует `unknown_capillary_hold_up` и блокирует последующие шаги;
     - Контролирует невязку баланса массы на каждом шаге и по всей сессии.

7. `addWater` / `consumeFreeWater`
   - Добавление и изъятие жидкости из свободной фазы.

8. `convertVolumeToMass` / `convertMassToVolume`
   - Конверсия с явным указанием принятой плотности $\rho_w = 1.0\text{ г/мл}$ (инженерное допущение).

## 11. Зафиксированные границы и физические ограничения этапа 2B.3.1

1. **Отсутствие экспериментальных констант для эталонов**:
   В каталоге `REFERENCE_TEAS` размерная константа $k_{\text{hyd}}$ для всех 6 эталонных чаёв имеет статус `unknown` и `value: null`. Расчёт баланса с эталонными чаями честно возвращает статус `unknown_hydration_profile`. Любая генерация чисел для эталонов без первичного протокола запрещена.
2. **Независимость капиллярного удержания**:
   Капиллярная ёмкость $V_{\text{interstitial}}$ не выводится и не может быть выведена из насыпной плотности сухого листа $\rho_{\text{bulk}}$ или коэффициента сорбции. Она задаётся для конкретной сессии как входной параметр либо остаётся неизвестной. Постоянство капиллярной ёмкости на протяжении сессии — инженерное упрощение модели, а не экспериментально подтверждённый закон.
3. **Разделение с тепловой моделью**:
   Тепловая модель (этап 2A) на данном этапе функционирует автономно: теплоёмкость влажного листа $C_{\text{leaf}} = m_{\text{dry}} c_{p, \text{dry}} + m_{\text{abs}} c_{p, \text{water}}$ пока не включена в тепловые уравнения, обратная связь по уменьшению массы свободной воды в тепловом ядре будет подключена на последующих этапах.
4. **Не является экспериментальной валидацией**:
   Реализованный модуль представляет собой математически строгое расчётное ядро, обеспечивающее сохранение массы и корректное распространение неопределённости, но не претендует на метрологическую калибровку реальных сортов без лабораторного стенда.
