**Версия документа:** 0.1.0-alpha  
**Статус:** Базовая архитектурная основа (Этап 1)  
**Проект:** Gongfu Cha Lab (Гунфу Ча Лаб)

## 1. Назначение и миссия продукта

**Gongfu Cha Lab** — это научно ориентированный веб-симулятор и исследовательская среда для моделирования процессов заваривания чая. 

Традиционная чайная культура часто оперирует метафорами и эмпирическими правилами («быстрый пролив», «кипяток для улунов»), которые трудно воспроизвести при смене посуды, порции или параметров воды. Gongfu Cha Lab строит мост между физико-химической реальностью экстракции веществ из растительного сырья и практикой осознанного заваривания.

Цель приложения:
1. **Моделирование кинетики экстракции**: предоставить пользователю прозрачный расчёт того, как температура, гидродинамика, степень измельчения, плотность скрутки листа и соотношение сырья к воде влияют на выход растворимых веществ (Total Dissolved Solids — TDS, полифенолы, алкалоиды, аминокислоты).
2. **Сравнение методов заваривания**: исследовать разницу между тремя фундаментальными парадигмами заваривания:
   - **Гунфу Ча (Gongfu Cha)** — многократные короткие проливы с практически полным сливом настоя;
   - **Лю Гэнь Пао (Liu Gen Pao)** — метод «сохранения корней настоя», при котором часть готового настоя (обычно 20–50%) остаётся в сосуде при каждом доливе свежей воды;
   - **Ленивое заваривание в кружке (Grandpa / Lazy Mug Style)** — листья непрерывно находятся в сосуде, вода доливается по мере выпивания.
3. **Подбор параметров под вкусовую цель**: в будущем позволить находить оптимальный рецепт (навеска, температура, экспозиция) для достижения желаемого баланса (умами/сладость vs плотность/горечь) без подмены физики фиктивными коэффициентами.

## 2. Ключевые требования и функциональные рамки

### 2.1. Функциональные возможности (целевое состояние)

| Модуль | Описание функционала | Текущий статус (Этап 1) |
| :--- | :--- | :--- |
| **Каталог чаёв** | Структурированная база сортов с физико-морфологическими и химическими свойствами, с явным разделением источников данных. | Реализован интерфейс, типизация и базовый эталонный набор с разметкой источников (`measured`, `estimated`, `unknown`). |
| **Мои чаи (Custom Teas)** | Добавление и локальное сохранение пользовательских сортов и партий, указание плотности скрутки, типа сырья и параметров. | Реализован интерфейс создания с валидацией источников значений и поддержкой неизвестных полей. |
| **Симулятор заваривания** | Интерактивная настройка параметров пролива (навеска, объём, температура, время, метод, посуда). | Реализован интерфейс настройки 3 методов с контролем физических единиц и валидацией границ. |
| **Результаты моделирования** | Отображение кинетики экстракции, пошаговых проливов, материального баланса. | Каркас результатов с честным статусом «Ожидает интеграции физико-химического ядра» (без выдуманных псевдоданных). |
| **Научная модель** | Интерактивный справочник физико-химических основ, допущений модели, размерностей и математических уравнений. | Реализован подробный раздел документации и архитектурного устройства модели в интерфейсе. |
| **Оптимизация рецепта** | Поиск параметров под заданный вкусовой профиль. | Специфицирован архитектурный интерфейс `IRecipeOptimizer`; реализация запланирована на последующих этапах. |

## 3. Границы текущего этапа (Этап 1: Архитектурный фундамент)

На текущем этапе **СТРОГО ЗАПРЕЩЕНО**:
- Использовать псевдонаучные генераторы случайных чисел для имитации экстракции.
- Выдавать приблизительные справочные значения за лабораторно измеренные факты.
- Приравнивать неизвестные параметры чая (`unknown`) к нулю.
- Загромождать проект серверной инфраструктурой или внешними зависимостями до стабилизации предметной модели.

Все экраны, функционал которых ожидает калибровки физического ядра, содержат ясные научные дисклеймеры и показывают структуру будущих данных без искажения реальности.
