**Версия:** 0.1.0-alpha  
**Статус:** Базовая архитектурная основа  

---

## 1. Архитектурные принципы предметной области

Предметная область чайной лаборатории опирается на следующие неизменные принципы:

1. **Характеристики чая — это входные параметры, а не результат симуляции.**  
   Чайный лист обладает объективными физико-морфологическими и химическими свойствами (масса, фракционный состав, влажность, пористость, начальное содержание водорастворимых сухих веществ). Моделирование не изменяет природу чая, а описывает его поведение в водной среде.

2. **Неизвестное значение не равно нулю (`Unknown ≠ 0`).**  
   В физической химии отсутствие данных о содержании теанина в конкретной партии не означает, что в ней 0 мг/г теанина. Любое скалярное значение в модели сопровождается метаданными о происхождении:
   - `MEASURED` — подтверждено лабораторным анализом (ВЭЖХ, рефрактометрия, титрование);
   - `ESTIMATED` — получено из справочных академических таблиц по данному типу сырья и региону;
   - `USER_DEFINED` — введено пользователем вручную по органолептическим или субъективным оценкам;
   - `UNKNOWN` — значение отсутствует. Модель не имеет права подставлять 0; она обязана либо использовать интервальную оценку, либо исключать данный показатель из строгих критериев.

3. **Явная размерность физических величин.**  
   Каждое числовое поле строго связано с единицей измерения:
   - Масса сырья: граммы ($g$);
   - Объём жидкости: миллилитры ($ml$);
   - Температура: градусы Цельсия ($^\circ C$);
   - Время: секунды ($s$);
   - Концентрация: миллиграммы на литр ($mg/L$) или граммы на литр ($g/L$);
   - Соотношение навески к воде: безразмерное отношение ($g:ml$).

## 2. Ключевые сущности системы

```
       +-------------------+         +-------------------+
       |     TeaSample     |         |   BrewingVessel   |
       +-------------------+         +-------------------+
                 \                             /
                  \                           /
                   v                         v
               +---------------------------------+
               |          BrewingSession         |
               +---------------------------------+
               | method: BrewingMethod           |
               | leafMassGrams: number           |
               | waterProfile: WaterProfile      |
               | steps: BrewingStepConfig[]      |
               +---------------------------------+
                               |
                               | (вычисляется ядром)
                               v
               +---------------------------------+
               |       SimulationResult          |
               +---------------------------------+
               | steps: StepExtractionResult[]   |
               | leafExhaustionCurve             |
               | cumulativeYieldPercent          |
               +---------------------------------+
```

### 2.1. `ValueWithOrigin<T>` — обёртка над физическими величинами

```typescript
export type DataOriginType = 'measured' | 'estimated' | 'user_defined' | 'unknown';

export interface ValueWithOrigin<T> {
  value: T | null;
  origin: DataOriginType;
  unit: string;
  confidence?: number; // 0.0 - 1.0 (доверительный интервал)
  sourceNotes?: string;
}
```

### 2.2. `TeaSample` — образец чая

```typescript
export type TeaCategory = 
  | 'green'        // Зелёный (неферментированный)
  | 'white'        // Белый (минимальная обработка)
  | 'yellow'       // Жёлтый (слабая ферментация, томление)
  | 'oolong_light' // Светлый улун (сферическая скрутка, слабая ферментация)
  | 'oolong_dark'  // Тёмный улун (продольная скрутка, прогрев на углях)
  | 'black'        // Красный / Чёрный (полная ферментация)
  | 'sheng_puer'   // Шэн пуэр (постферментированный естественный)
  | 'shou_puer'    // Шу пуэр (водуй, искусственное состаривание)
  | 'hei_cha';     // Чёрный чай (хэй ча)

export type LeafMorphology = 
  | 'whole_bud'             // Чистая почка (например, Цзинь Цзюнь Мэй, Инь Чжэнь)
  | 'bud_and_leaves'        // Почка и 1-2 листа
  | 'mature_open_leaves'    // Крупные зрелые раскрытые листья
  | 'compressed_cake_chunk' // Прессованный блин / кирпич (тугая прессовка)
  | 'tightly_rolled_ball'   // Сферическая тугая скрутка (Те Гуаньинь, тайваньские улуны)
  | 'strip_rolled';         // Продольная полосовая скрутка (Да Хун Пао, Даньцуны)

export interface TeaSample {
  id: string;
  name: string;
  category: TeaCategory;
  originRegion: string;
  harvestYear?: number;
  morphology: LeafMorphology;
  
  // Физико-структурные параметры
  hydrationSpeedFactor: ValueWithOrigin<number>; // Относительный коэффициент гидратации листа
  waterAbsorptionRatio: ValueWithOrigin<number>; // Сколько грамм воды удерживает 1 грамм сухого листа (типично 2.0 - 3.2 г/г)
  leafDensityGPerCm3: ValueWithOrigin<number>;   // Насыпная/истинная плотность

  // Химические резервуары экстрактивных веществ (г/100г сухого вещества или %)
  totalSolubleFraction: ValueWithOrigin<number>; // Общая доля водорастворимых сухих веществ (типично 30-45%)
  caffeineEstimate: ValueWithOrigin<number>;     // Алкалоиды (2-5%)
  polyphenolsEstimate: ValueWithOrigin<number>;  // Катехины, теафлавины, теарубигины
  theanineEstimate: ValueWithOrigin<number>;     // Аминокислоты (1-4%)

  isCustom: boolean;
  notes?: string;
}
```

### 2.3. Методы заваривания (`BrewingMethod`)

1. **`GONGFU_CHA` (Гунфу Ча / Полный пролив)**:
   - Сосуд: чайник или гайвань малого объёма (80–180 мл).
   - Высокое соотношение навески к воде: $1:12 - 1:25$ ($g:ml$).
   - Цикл: короткий контакт (3–30 с), практически полный слив настоя ($V_{\text{residual}} \approx 0$).
   - Динамика: каждый пролив отражает кинетическую волну экстракции веществ с разной молекулярной массой и скоростью диффузии.

2. **`LIU_GEN_PAO` (Лю Гэнь Пао / Сохранение корня настоя)**:
   - Метод удержания базового раствора: при каждом проливе сливается только часть настоя (обычно 50–70%), а остаток ($V_{\text{retained}} = 30-50\%$) остаётся в сосуде с листьями.
   - Свежая горячая вода вливается в концентрированный остаток.
   - Динамика: сглаживание пиков горечи, буферизация концентрации, непрерывный градиент между шагами.

3. **`LAZY_MUG` (Открытое настаивание в кружке / Grandpa Style)**:
   - Листья помещаются на дно кружки или колбы (200–500 мл).
   - Низкое начальное соотношение навески к воде: $1:50 - 1:100$ ($g:ml$).
   - Листья не извлекаются; напиток отпивается до половины или трети, после чего доливается свежая горячая вода.
   - Динамика: квазистационарная диффузия с медленным падением температуры и ступенчатым разбавлением.

## 3. Матрица разделения интерфейса и вычислительного ядра

| Слой | Ответственность | Зависимости |
| :--- | :--- | :--- |
| **UI Components (`src/components`, `src/features`)** | Отображение элементов управления, валидация полей ввода, визуализация состояний, анимация. | Зависит от доменных типов `src/domain/*`. НЕ содержит физических уравнений. |
| **Domain Layer (`src/domain/*`)** | Определение типов, инвариантов, единиц измерения, правил происхождения данных (`DataOrigin`). | Чистый TypeScript без внешних зависимостей. |
| **Engine Interfaces (`src/engine/*`)** | Контракты расчёта (`IExtractionEngine`, `IBrewingMethodSimulator`). | Зависит только от `src/domain/*`. |
| **Reference Data (`src/data/*`)** | Эталонный каталог чаёв, справочные свойства материалов посуды. | Реализует типы `TeaSample` с честной разметкой `origin`. |
